## ❓ 常见问题

**这些是官方原版吗？**
是。所有链接均直接指向腾讯官方 CDN，本仓库只做地址整理，不修改、不转发、不托管安装包。

**怎么安装历史版本？**
先备份聊天记录，卸载当前版本后再安装历史版本（Android 不支持直接降级安装）。

**为什么同一个版本号有多个文件？**
官方会针对不同 CPU 架构或构建号发布多个安装包，请在版本页选择对应架构下载。
